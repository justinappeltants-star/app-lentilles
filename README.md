# App Lentilles

Application de suivi des jours de port de lentilles de contact. Le projet est conçu pour proposer un calendrier de suivi, des statistiques et des réglages personnalisables dans une interface simple.

## État du projet

Le projet est en développement. Les comptes utilisateurs, la synchronisation des données et les fonctions d’administration nécessitent encore une configuration du backend et des tests avant une mise en production.
